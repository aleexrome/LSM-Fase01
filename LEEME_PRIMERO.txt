💡 SISTEMA CSV (NUEVO):

  ✅ 100% confiable (no depende de audio)
  ✅ Simple (timestamps en archivo CSV)
  ✅ Editable (corregir manualmente)
  ✅ Rápido (sin procesamiento FFT)

  ❌ Sistema FSK (viejo) ELIMINADO:
     - Problemas de decodificación (50% éxito)
     - Dependencia de audio codificado
     - Imposible corregir errores

📞 COMANDOS ÚTILES:

  python keyboard_recorder.py test.mp4

  # Grabar en Raspberry Pi:
  python3 raspberry_recorder.py video.mp4

  # Procesar video:
  python lsm_processor_csv.py --input video.mp4

  # Ver ayuda:
  python lsm_processor_csv.py --help
